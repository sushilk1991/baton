# Code of conduct

Treat contributors and users with respect. Critique code and claims with
evidence. Accept corrections, keep discussion relevant, and respect other
people's time and privacy.

Harassment, threats, discriminatory abuse, sexual attention, doxxing, and
deliberate disruption are unacceptable. Do not post another person's
private information or private messages without permission. These rules
apply in repository discussions, issues, pull requests, and other project
spaces.

Maintainers may remove content, close a discussion, or restrict participation
to address violations. They should explain decisions where doing so does
not expose private information. Good-faith reports and appeals deserve
review without retaliation.

To request private contact, open an issue titled “Conduct contact request”
without names or incident details. The maintainer will arrange a private
channel; no dedicated private conduct-reporting address is established yet.
If public contact would expose you, wait for a private channel rather than
posting sensitive details.
